适用于移动H5-8 Telnet教程1，登录光猫普通账号新建标签页输入http://192.168.1.1/getpage.gch?pid=1002&nextpage=tele_sec_tserver_t.gch进入telnet设置界面。勾选启用，可以自己设置telnet账号密码。默认是CMCCAdmin aDm8H%MdA2，Telnet输入CMCCAdmin后回车输入密码aDm8H%MdA3，输入sidbg 1 DB p DevAuthInfo // 显示信息 不建议修改超密，直接复制查询即可。 4，输入sidbg 1 DB set DevAuthInfo 0 User CMCCAdmin后回车，这条命令的意思是改超管账户为CMCCAdmin（也可以自定义）5，sidbg 1 DB p DevAuthInfo 0 Pass aDm8H%MdA（超管密码也可以自定义。）6，输入sidbg 1 DB save 可以登录超管了。
