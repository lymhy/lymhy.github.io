高通骁龙芯片随身WiFi（棒子）刷机教程

前言

本教程适用于高通骁龙芯片的随身WiFi（简称棒子）的教程，不适用其他芯片和大厂棒子型号。

刷机前检查棒子功能是否正常，部分文件可能会报毒，事先添加系统的白名单或关闭实时保护。

1. 打驱动

安装 adb 和 9008 驱动，双击安装启动文件即可。

ADB 运行方法是点击文件夹路径栏空白处输入 cmd 回车。

8. Debian 安装后续操作

8.1 安装 Debian

  • 下载 base 和 Debian 文件并解压。
  • 进入 base 文件夹，在路径栏空白处输入 cmd 回车。
  • 插入棒子等待棒子完全启动。
  • 回车进入 fastboot。
  • 双击 base 文件夹中的 flash bat，按照提示进行操作。
  • 进入 Debian 文件夹，双击 flash bat，等待程序完成。
  • 重新插拔棒子，电脑显示 handsome 外设。

8.4 安装完成

Debian 安装完毕。笔者认为棒子 Debian 不适合安装图形界面，现在的棒子基本都是 4GB 内存，如果不担心内存爆满可以尝试一下。

Tips：

  • 方法一：驱动程序 → 更新驱动程序 → 浏览我的电脑 → 网络适配器 → Microsoft → 基于远程 NDIS 设备 → 无视风险 → 确定更新，重新插拔设备。
  • 方法二：进入电脑设备管理器，双击新出现的位置设备，或者在 Android Device 下查看有没有 Android Composite ADB Interface 驱动。如果没有，右键更新驱动程序 → 浏览我的计算机以查找驱动程序软件 → 让我从计算机上的可用驱动程序列表中选取 → 选择 Android Composite ADB Interface → 下一步。

如果不需要插卡，可以刷一个一键刷入版的删减版 Debian，减少内存占用。
