  1. 注册/登录
    访问 Algolia，注册账号或登录。

  2. 创建索引 Index
    登录后进入 Dashboard，根据引导创建一个新的 Index（你可以自定义名称，如：my_blog）。

  3. 获取 API 信息
    在 API Keys 页面找到以下参数：

    • Application ID
    • Search-Only API Key
