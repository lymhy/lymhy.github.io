下载并安装 Node.js

首先从官网下载 Node.js 安装包。
由于系统会默认将本地仓库放在 C 盘，在修改过程中经常忘记文件位置，为了管理方便，需要更改 npm 的全局目录 node_global 和 npm 缓存文件夹 node_cache。
如果没有设置全局目录 node_global，那么全局安装的文件将会保存到：C:\Users\自己的计算机名\AppData\Roaming\npm

手动修改 C:\Program Files\nodejs\node_global 和 node_cache 目录权限

  1. 进入 C:\Program Files\nodejs\
  2. 右键 → “属性” → “安全”
  3. 选择你的用户，并点击 “编辑权限”
  4. 选中 “完全控制” 并 “应用”
